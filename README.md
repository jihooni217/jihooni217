### 🚦 FlowLight

**Upstage Solar Pro 4** 로 교차로 신호를 분석 · 계획 · 평가하는 Multi-Agent 데모

- Agent 출력은 **JSON Schema** 로 형식을 고정
- 규칙 기반 **Guardrail** 을 통과한 계획만 적용
- **FastAPI + SSE** 로 판단 과정을 단계별 스트리밍
- 공공 교통량 → 발생률 → 시뮬레이션. 대기 차량은 결과로만 사용
- 한국식 4현시, 좌회전 전용 차로, 감응 신호, 시간대별 재분석
- 보행자 없는 교차로, 시드 10개 평균: 통과 +11%, 정지 차량 −16%
- 서울시 실측 교통량(숭례문 일대 하루치)을 두 번째 프로파일로 제공
- 설치 없이 브라우저에서 바로 체험 (녹화된 실제 응답 재생), 테스트 286개

### 🚗 Raspbot 자율주행

카메라 한 대로 트랙 한 바퀴를 스스로 달리는 소형 자율주행차 · **Raspberry Pi 5** (대구대 PBL 3조 조장)

- OpenCV 차선 추적, 바닥 색에 따라 가속·감속
- YOLO로 사람·STOP 표지를 보면 정지, START 선에서 자동 정지
- **지시서 주도 AI 협업**: 내가 규칙과 숫자 성공 기준을 쓰고, Codex가 코드를 작성
- 바퀴를 돌리기 전에 사진 시험·가짜 장치 시험으로 먼저 검증
- 실제 트랙 7판 모두 완주 · 사진 시험 모서리 판단 28% → 81%
- 글 명령은 AI가 정해진 동작 11개 중 하나만 고르는 가드레일 구조
