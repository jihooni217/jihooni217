## 🚦 Featured Project

### [FlowLight - AI Traffic Signal Optimization](https://github.com/jihooni217/FlowLight-AI-Traffic-Signal)

> LLM 기반 Multi-Agent를 활용한 실시간 교통 신호 최적화 시스템

FlowLight는 교차로의 교통 상태를 분석하고,  
LLM Agent가 최적의 신호 계획을 생성·평가·검증한 뒤  
CityFlow 시뮬레이션에 적용하는 AI 기반 교통 신호 최적화 프로젝트입니다.

**주요 구현 내용**

- FastAPI 기반 AI Agent Backend 구현
- SSE(Server-Sent Events)를 활용한 실시간 스트리밍 응답
- Upstage Solar API 기반 LLM Agent 연동
- Traffic Analysis / Signal Planning / Plan Evaluation Agent 구조 설계
- Guardrail 및 JSON Validation 기반 안전 검증
- AI 적용 전후 시뮬레이션 비교 및 결과 분석
